# Passenger Information Display System (PIDS)

## What is PIDS?

PIDS stands for Passenger Information Display System.

It is a Metro Railway system used to provide visual information
to passengers through displays installed at stations.

## Information Displayed

Depending on the Metro system configuration, PIDS can display
information such as:

- Train destination
- Arrival information
- Departure information
- Train/route information
- Passenger messages
- Service information
- Emergency or operational messages

## ATS to PIDS Information Flow

In a typical Metro environment, ATS provides train-related
operational information to the PIDS/PAS system.

The PIDS/PAS software processes the received information and
updates the appropriate passenger displays.

Basic flow:

ATS
↓
PIDS/PAS Software
↓
PIDS Display
